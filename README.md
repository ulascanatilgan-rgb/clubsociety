# Club Society

Investment coaching web-app MVP.

## Run locally
1. npm install
2. npm start
3. Open http://localhost:3000

## Railway
The app is Railway-ready. Railway should use the default Node build and run npm start. The server listens on process.env.PORT.

## Current MVP
- 10 sectors / 100-company research universe
- Technology and macro intelligence demo
- Company scorecards
- Investor Profile Coach
- Educational portfolio visualisation and editor
- Club Society model portfolio preview

Demo scores and news are placeholders and must be replaced with validated data before production. No brokerage connection or trade execution.
